================================================================================
🧱 COMPONENT-FIRST EXTRACTION PROTOCOL (FROM DESIGNS)
================================================================================

When inspecting the UI design folder or detailed explanation, the AI MUST extract
components in this exact order BEFORE planning full pages:

Step 1: Extract Design Tokens
• Primary, Secondary, Background, Surface, Border colors (Exact Hex codes).
• Typography: Font families, font weights, scale (Display, Headline, Title, Body).
• Spacing & Layout: 4dp/8dp baseline grid, card paddings (16dp).
• Elevation / Corner Radii: e.g., 12px subtle radius or 28px puffy clay radius.

Step 2: Extract Reusable Atoms & Molecules (Component-First)
• Buttons      : Primary CTA, Outlined, Ghost, Icon button, Loading spinner button.
• Text Inputs  : Standard field, search bar, dropdown selector, password with toggle,
                 OTP verification boxes.
• Containers   : Content card, product/item tile, summary header, segmented tabs.
• Navigation   : Top AppBar with action icons, Bottom Navigation Bar with badge counters.
• Overlays     : Bottom sheet modal, confirmation dialog, snackbar notification toast.

Step 3: Extract Page Inventory from Designs
• Analyze all screens provided in the design folder.
• Name each page (e.g. Splash, Onboarding, Login, Feed, Search, Details, Cart, Profile).
• Assign which reusable components from Step 2 are assembled into each page.

Step 4: Extract Functional Features from Designs
• Look at visible UI elements to deduce the app's features:
  - Search bar + Filter icon  ──► Search & Filtering Feature
  - Heart icon on items       ──► Favorites / Wishlist Feature
  - Floating cart badge       ──► Shopping Cart & Checkout Feature
  - Bell icon with unread dot ──► Push & In-App Notification Feature
  - Camera icon on avatar     ──► Profile Image Upload Feature
