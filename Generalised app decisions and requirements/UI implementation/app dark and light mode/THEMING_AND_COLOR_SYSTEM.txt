--------------------------------------------------------------------------------
🎨 1. SEMANTIC COLOR TOKENS
--------------------------------------------------------------------------------

Never use raw colors like Colors.black or Color.White directly in UI widgets.
Map all styling through these semantic tokens:

+------------------+------------------+------------------+---------------------+
| Semantic Token   | Light Mode       | Dark Mode        | Usage Description   |
+------------------+------------------+------------------+---------------------+
| background       | #F8FAFC          | #0F172A          | Base window canvas  |
| surface          | #FFFFFF          | #1E293B          | Cards, sheets, bars |
| surfaceSubtle    | #F1F5F9          | #334155          | Secondary chip/box  |
| textPrimary      | #0F172A          | #F8FAFC          | High-contrast text  |
| textSecondary    | #64748B          | #94A3B8          | Subtitles, captions |
| primary          | Brand Accent     | Lightened Accent | CTAs, active states |
| border           | #E2E8F0          | #334155          | Dividers, borders   |
| error            | #EF4444          | #F87171          | Destructive/errors  |
| success          | #10B981          | #34D399          | Confirmations       |
+------------------+------------------+------------------+---------------------+
