--------------------------------------------------------------------------------
🔄 2. SCHEMA MIGRATION STRATEGY
--------------------------------------------------------------------------------

• Versioned Migrations: Every DB schema upgrade must have an explicit integer
  version (v1 -> v2 -> v3).
• Destructive Fallback Forbidden: Never invoke destructive fallback in production.
  Always write an explicit SQL alter table or data migration script.


--------------------------------------------------------------------------------
📡 3. REACTIVE UI SYNCHRONIZATION
--------------------------------------------------------------------------------

• Queries must return reactive streams (e.g. Stream<List<T>> in Flutter or
  Flow<List<T>> in Kotlin).
• When background synchronization inserts or updates rows, the UI must
  automatically update without full-screen refreshes.
