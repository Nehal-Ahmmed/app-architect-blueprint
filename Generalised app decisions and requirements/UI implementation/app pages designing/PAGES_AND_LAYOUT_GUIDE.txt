================================================================================
📄 UI IMPLEMENTATION: APP PAGES & LAYOUT ARCHITECTURE
================================================================================

[AI INSTRUCTION]
When assembling screens from design files:
1. Every screen layout must match the design mockups 100% SAME-TO-SAME.
2. Every interactive button must have its navigation destination explicitly mapped.
3. Every page shift / transition must use smooth, specified animations (Hero, Slide).

--------------------------------------------------------------------------------
🎬 1. PAGE TRANSITION & SCREEN SHIFT ANIMATION RULES
--------------------------------------------------------------------------------

Never use abrupt or instant screen jumps. Use defined page route transitions:
1. Horizontal Slide & Parallax:
   • Forward Navigation : New page slides in from Right (Curve: Curves.easeOutCubic, 280ms),
                          previous page recedes slightly with subtle dimming.
   • Back Navigation    : Top page slides out to Right, revealing previous page.
2. Shared Element (Hero) Transitions:
   • Product cards, avatar images, and title text must smoothly expand/morph
     into their full-size positions on the detail screen.
3. Modal Bottom Sheet Slide-Up:
   • Bottom sheets slide up smoothly from the bottom with background dimming (300ms).
4. Tab Fade-Through / Cross-Fade:
   • Switching bottom navigation tabs uses a 200ms subtle cross-fade to prevent jarring.


--------------------------------------------------------------------------------
🔍 2. BUTTON-TO-ACTION NAVIGATION MAPPING PLAN
--------------------------------------------------------------------------------

During page planning, every clickable element MUST be documented in this format:
• Button [Name] ──► Action (Navigate to /route OR Open Modal OR Trigger Event)
• Example:
  - "Get Started" Button ──► Navigates to /auth/login with slide transition.
  - "Filter" Icon Button  ──► Opens FilterModalBottomSheet with slide-up.
  - "Profile Avatar"      ──► Navigates to /profile with Hero transition.


--------------------------------------------------------------------------------
🏛️ 3. MASTER SCREEN SCAFFOLD PATTERN
--------------------------------------------------------------------------------

[Screen Scaffolding]
├── Safe Area & Insets (Top status bar & bottom navigation bar handling)
├── Top App Bar (Title, Navigation back button, Trailing action icons)
├── Body Viewport (SingleChildScrollView or CustomScrollView with Slivers)
│   ├── Responsive Content Container (Max width constraint for tablets/web)
│   └── RefreshIndicator (Pull-to-refresh where applicable)
├── Floating Action Button / Sticky Bottom Action Bar
└── Global Modal Overlay (Full-screen loading indicator or Offline banner)
