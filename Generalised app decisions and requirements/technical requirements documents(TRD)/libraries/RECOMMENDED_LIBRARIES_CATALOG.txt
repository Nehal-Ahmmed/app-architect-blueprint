🗺️ 2. NAVIGATION & ROUTING
--------------------------------------------------------------------------------

[Flutter]
• go_router     : Declarative, URL-based, deep link parsing, dynamic auth guards.
                  Status: [PRIMARY DEFAULT] ⭐⭐⭐⭐⭐
• auto_route    : Compile-time route generation, strong typing.
                  Status: Alternative ⭐⭐⭐⭐

[Android (Kotlin)]
• Navigation 3  : Modern Kotlin DSL, type-safe backstack, multiplatform-ready.
  (Nav3)          Status: [PRIMARY DEFAULT] ⭐⭐⭐⭐⭐
• Nav Compose   : Traditional Jetpack Navigation for Compose.
                  Status: Alternative ⭐⭐⭐⭐
• Voyager       : ScreenModel architecture, multiplatform tab/stack navigation.
                  Status: [PRIMARY DEFAULT FOR KMP] ⭐⭐⭐⭐⭐

🌐 3. NETWORKING & HTTP CLIENTS
--------------------------------------------------------------------------------

• Flutter      : dio + retrofit (Interceptors, retry policies, progress tracking)
                 Status: [PRIMARY DEFAULT]
• Kotlin       : Ktor Client or Retrofit 2 + Kotlinx Serialization (Coroutine-first)
                 Status: [PRIMARY DEFAULT]
• Spring Boot  : RestClient (Spring 6) or WebClient (Reactive non-blocking)
                 Status: [PRIMARY DEFAULT]


--------------------------------------------------------------------------------
💾 4. LOCAL PERSISTENCE & DATABASE
--------------------------------------------------------------------------------

• Flutter (Fast NoSQL)   : isar / hive_ce (Fast key-value, caching, offline feeds)
• Flutter (Relational)   : drift (SQLite ORM with type-safe Dart queries)
• Android Native         : Jetpack Room with KSP (Google standard SQLite ORM + Flow)
• Kotlin Multiplatform   : SQLDelight or Room KMP (Cross-platform SQL generator)
• Backend (Relational)   : PostgreSQL + Spring Data JPA (ACID transactions)


--------------------------------------------------------------------------------
🔐 5. SECURE STORAGE (TOKENS & CREDENTIALS)
--------------------------------------------------------------------------------

• Flutter      : flutter_secure_storage (Android KeyStore + iOS Keychain)
• Android      : EncryptedSharedPreferences (Jetpack Security MasterKey AES-256)
• Spring Boot  : Spring Security Crypto (BCrypt) + Vault / Environment Secrets
