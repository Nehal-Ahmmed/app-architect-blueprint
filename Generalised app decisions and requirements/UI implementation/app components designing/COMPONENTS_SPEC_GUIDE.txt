--------------------------------------------------------------------------------
🧱 2. CORE COMPONENT CATALOG & SPECIFICATIONS
--------------------------------------------------------------------------------

1. Buttons & Call-to-Actions (CTAs)
   • Primary Button   : Full brand accent, minimum touch target height 48dp
                        (WCAG accessible), rounded radius matching design style.
                        Must support loading spinner state.
   • Outlined Button  : 1.5px border matching primary accent, transparent background.
   • Ghost / Text     : Transparent background, text highlight with ripple effect.
   • Icon Button      : Symmetrical touch target (min 44x44dp), tooltipped on long press.

2. Input Fields & Forms
   • Text Field       : Label, placeholder, optional leading icon, trailing clear
                        or visibility toggle, helper/error text below.
   • States           : Default, Focused (accent border + glow), Error (#EF4444),
                        Disabled (opacity 0.4).
   • Input Formatting : Phone masks, currency formatting, auto-advancing OTP fields.

3. Cards & Containers
   • Standard padding : 16dp.
   • Styling          : Elevated or bordered according to the chosen UI aesthetic
                        (Claymorphism, Glassmorphism, Material 3, etc.).
   • Tap Feedback     : Haptic vibration (light impact) and subtle scale (scale 0.98).

4. Dialogs & Bottom Sheets
   • Bottom Sheet     : Draggable dismiss handle, rounded top corners (24dp),
                        dimmed backdrop (rgba(0, 0, 0, 0.5)).
   • Confirmation Box : Centered modal, max width 400dp, clear primary and cancel actions.
   • Toast / Snackbar : Floating banner, rounded corners, auto-dismiss in 3s with Undo.
