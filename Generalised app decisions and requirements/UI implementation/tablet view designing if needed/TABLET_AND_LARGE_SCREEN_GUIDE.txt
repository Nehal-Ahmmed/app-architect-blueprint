💻 UI IMPLEMENTATION: TABLET & LARGE SCREEN ADAPTIVE LAYOUTS
================================================================================

[AI INSTRUCTION & ADAPTIVE ARCHITECTURE]
Apply these native Flutter patterns for tablets, foldables, and desktops.
Proportional zoom (e.g. ScreenUtil) is STRICTLY FORBIDDEN.
Adapt the layout structure, columns, and navigation widgets based on available space.

--------------------------------------------------------------------------------
🪟 1. MASTER-DETAIL MULTI-PANE PATTERN
--------------------------------------------------------------------------------

On mobile (< 600dp), selecting an item pushes a new full-screen route.
On tablet / desktop (>= 840dp), display a synchronized side-by-side pane:

+------------------------------------------------------------------------------+
| [Navigation Rail] | [Master Pane: 35%]   | [Detail Pane: 65%]                |
|                   |                      |                                   |
| Home              | Item 1 (Selected)    | Item 1 Full Detail & Actions      |
| Messages          | Item 2               | Interactive controls              |
| Settings          | Item 3               | Analytics / Statistics            |
|                   | Item 4               |                                   |
+------------------------------------------------------------------------------+


--------------------------------------------------------------------------------
🧭 2. ADAPTIVE NAVIGATION WIDGETS
--------------------------------------------------------------------------------

• Mobile (< 600dp)            : BottomNavigationBar / NavigationBar.
• Small Tablet (600 - 839dp)  : NavigationRail (vertical icon strip on left).
• Large Tablet / Desktop (840dp+) : NavigationDrawer (expanded left panel with labels).


--------------------------------------------------------------------------------
📝 3. MULTI-COLUMN GRIDS & CONTENT BOUNDS
--------------------------------------------------------------------------------

• Use GridView.builder with SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 320)
  so columns increase naturally as screen widens without code change.
• Enforce ConstrainedBox(constraints: BoxConstraints(maxWidth: 680)) on reading feeds
  and form dialogs to prevent awkward horizontally stretched text.
