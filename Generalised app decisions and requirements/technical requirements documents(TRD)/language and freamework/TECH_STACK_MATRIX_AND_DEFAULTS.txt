================================================================================
1️⃣ PRESET: FLUTTER & DART (CROSS-PLATFORM MOBILE & DESKTOP)
================================================================================
• Target Platforms : Android, iOS, Web, Desktop (Windows, macOS, Linux)
• Language & SDK   : Dart 3.x / Flutter 3.x+ (Sound Null Safety)

[CASCADING DEFAULTS]
* State Management : flutter_riverpod + riverpod_annotation (v2.x with code generation)
  - Why: Compile-safe, no BuildContext dependency, auto-disposal, easily testable.

* Navigation       : go_router
  - Why: Declarative URL routing, deep link parsing, dynamic redirect guards on auth.

* Networking       : dio + retrofit + pretty_dio_logger
  - Why: Interceptors for auto JWT refresh tokens, retry policies, progress tracking.

* Local Database   : isar or hive_ce
  - Why: Ultra-fast NoSQL storage on device, zero native bridge overhead.

* Secure Storage   : flutter_secure_storage
  - Why: Hardware-backed KeyStore on Android, Keychain on iOS, Protected Data on Win.

* Serialization    : freezed + json_serializable
  - Why: Immutable data classes, copyWith, pattern matching, auto JSON mapping.

* UI & Responsive  : 100% Native Flutter (LayoutBuilder, MediaQuery, Expanded/Flexible)
  - Why: Adaptive breakpoints (600/840/1200dp). ScreenUtil zoom-scaling is strictly excluded.

* Architecture     : Feature-First Clean Architecture
  - Structure: core/ + features/<feature>/{presentation, domain, data}


================================================================================
2️⃣ PRESET: ANDROID NATIVE / JETPACK COMPOSE (KOTLIN)
================================================================================
• Target Platforms : Android (Phone, Tablet, Foldable, WearOS)
• Language & SDK   : Kotlin 2.x (K2 Compiler enabled)

[CASCADING DEFAULTS]
* UI Toolkit       : 100% Jetpack Compose (Declarative UI)

* Navigation       : Navigation 3 (Nav3) or androidx.navigation:navigation-compose
  - Why: Nav3 is the modern type-safe standard, multiplatform-ready backstack.

* Architecture     : MVI (Model-View-Intent) or MVVM with Unidirectional Data Flow
  - Why: Single source of truth via immutable UiState exposed through StateFlow.

* DI Framework     : Koin (lightweight, pragmatic) or Hilt / Dagger (compile-time)

* Networking       : Ktor Client or Retrofit 2 with Kotlinx Serialization
  - Why: Coroutine-first, reflection-free, lightning-fast serialization.

* Local Database   : Jetpack Room (with KSP)
  - Why: Google standard relational SQLite ORM with reactive Flow<List<T>>.

* Secure Storage   : EncryptedSharedPreferences (Jetpack Security) & Android KeyStore
  - Why: Hardware-backed AES-256 GCM encryption for user tokens.

* Concurrency      : Kotlin Coroutines & Reactive Flows

================================================================================
